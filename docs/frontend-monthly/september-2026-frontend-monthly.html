Theme 1 · New feature

Gateway credits

The AI Gateway wallet became a visible, metered product surface across the editor — 13 PRs, and a new name at the end of the window.

New this monthTop-up flowCredential pickerCached balance
  • A new name — "n8n credits" and "n8n Connect" copy became Gateway credits across the UI, and the free AI credits callout texts were adjusted. #37267 · #35668
  • Top up, if you may — a role-aware top-up flow lets eligible users add credits; the credits pill switches state after a top-up or when the allowance runs out; the settings link is back. #35873 · #36239 · #36435
  • Credits where you need them — the node credential picker shows and offers Gateway credits, and the agent tools modal gained an n8n credits section. #35758 · #36183
  • Credits that stick — copying a workflow keeps its credits; an Assistant-built workflow keeps its managed credits; the credit banner is its own card above detached chat inputs. #37253 · #37198 · #37082
  • Fewer wallet requests — the balance is cached; n8n Connect usage is hidden when aiGatewayCloudUbb is on; balance clicks are tracked. #36725 · #35978 · #36194

Theme 7 · Trust & Security

Settings, permissions & MCP

A stricter shell, permissions split finer, and MCP as a governed surface.

A stricter shell

n8n now serves a nonce-based Content-Security-Policy on its HTML pages. Community packages that need an unsupported node API are skipped at startup instead of breaking it.#36749 · #37449

Permissions, split finer

Instance Settings permissions became granular custom-role options; a project:manageUsers scope gates membership; a nodeTypePolicy RBAC scope landed; browser credential creation is gated; the UI warns about self-escalation.#36802 · #36243 · #37538 · #36931 · #36458

MCP, governed

Auto-expose for new workflows is a settings toggle and MCP Access was reordered around it; MCP supports folder creation and workflow moves; the ChatGPT one-click connector is back; server usage goes to log streaming.#35828 · #36706 · #35964 · #35396 · #33300

Also: a Git connections settings page with a public API, a clear no-access message when SSO role mapping denies a login, configurable Azure Key Vault endpoints, the "Any workflow" caller policy deprecated, and screen-reader support for scope selector tool pills. #36991 · #36272 · #36407 · #35214 · #36350 · #37159

Theme 9 · Architecture

The editor as a platform

August moved stores and composables into packages. This window the module SDK became load-bearing: three features left editor-ui, and a registry replaced the shell's modal list.

Module SDKModal registryFrontend modulesThinning shims
  • The SDK became load-bearing — module SDK push and command registries are wired into the shell, and the Instance-AI credits push routes through it. #34422 · #34436
  • Features left the shell — OpenTelemetry and the instance registry were extracted into module packages, with a route-name collision guard; registration stays silent after a re-login. #36679 · #36645 · #36325 · #36398
  • A modal registry — two-phase registration and per-feature fragments landed, shell-held modals moved to their features, state derives from the registry, and unknown keys render closed instead of throwing. #36147 · #36317 · #35859 · #35625
  • Shims dropped — settings.store and users.store importers were repointed to @n8n/stores and their shims deleted; useStorage consumers moved to @n8n/composables. #35459 · #35330 · #35443
  • One entry per feature — insights got a single public entry, formatBytes and toMb were deduplicated into @n8n/utils, and the typed telemetry boundary was tightened. #36821 · #36218 · #35350
