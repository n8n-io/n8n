# i18n

Applies to: `packages/frontend`.

`baseText(key, { interpolate })` takes an untyped record and vue-i18n leaves
an unmatched placeholder in the output. Nothing checks those names against
`en.json`.

- An `interpolate` key not matching the `{placeholder}` in that string,
  including a case difference such as `docUrl` against `{docURL}`. The user
  sees the raw placeholder or nothing.
- `i18n.baseText` passed as a bare function reference. It is a class method
  reading `this`, so detaching it returns the key instead of the translation.
  Pass the `i18n` object.
- Punctuation, separators or brackets hardcoded around a translated string in
  a template. Composition differs per locale; put them in the string.
Do NOT flag a missing non-`en` translation, or wording itself unless it
contradicts copy the same PR adds.
