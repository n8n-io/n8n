# Colour

Primitive colour scales live in `_primitives.scss`. Prefer semantic tokens from `_tokens.scss` in product UI (for example `--text-color`, `--background--surface`) so themes stay consistent.

Each hue scale uses steps from lightest (`50`) to darkest (`950`). Hover a swatch for the token and resolved value. Click to copy the token name.
