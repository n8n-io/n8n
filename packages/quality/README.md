# Quality engineering

Each area owns workspaces and suites. Suites can reuse shared runner configuration and fixtures across workspace boundaries.

| Area | Owns | Start here |
| --- | --- | --- |
| Policy | Repository rules and static checks | [Policy](policy/README.md) |
| Testing | Test selection, architecture checks, and the Playwright runner | [Testing](testing/README.md) |
| Environments | Services and deployment stacks for tests | [Environments](environments/README.md) |
| Efficiency | Resource measurements, microbenchmarks, and load-test tools | [Efficiency](efficiency/README.md) |

Use the [Playwright suite map](testing/playwright/README.md#choose-a-suite) to find existing browser, accessibility, memory, and infrastructure suites.
